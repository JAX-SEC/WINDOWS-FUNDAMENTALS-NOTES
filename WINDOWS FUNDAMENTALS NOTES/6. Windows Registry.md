The **Windows Registry** can be a daunting subject for most and the goal of this write up is to demystify this core component of the Windows OS under the lens of Cybersecurity. As per Microsoft, the registry is a central hierarchical database used to store information necessary to configure the system for one or more users, applications, and hardware devices. The data is structed in a tree format. Each node in the tree is called a *key* and each key can contain both *subkeys* and data entries called *values* which when grouped together is often referred to as a Hive. With this in mind, a Registry Hive is a group of keys, subkeys, and values stored in a single file on the disk.

The Registry Editor

The registry contains the following 5 core hives(or root keys):

- **HKEY\_CLASSES\_ROOT**
- **HKEY\_CURRENT\_USER**
- **HKEY\_LOCAL\_MACHINE**
- **HKEY\_USERS**
- **HKEY\_CURRENT\_CONFIG**

You can view the registry by searching for “registry” via the Windows search bar or by simply pressing **Windows Key** + **R** and typing “regedit”. The registry hives can also be located via the following directory: *C:\\Windows\\System32\\config*

> **HKEY\_CLASSES\_ROOT**

HKCR is the abbreviation for this Hive. The Information that is stored here makes sure that the correct program opens when you open a file by using Windows Explorer.

***Notable subkeys:***

- **.exe**: Contains information about how executable files should be handled.
- **.txt**: Contains information about handling text files.
- **.jpg,.png,.gif, etc.**: Contains information about handling image file formats.
- **.html,.htm**: Contains information about handling HTML files.
- **Directory**: Stores settings related to folders and directories.

***Prime targets:***

1. **File Associations**: Look for unusual or unauthorized changes in file associations. Malware may alter these to open certain file types with malicious programs.
2. **COM Object Registrations**: Monitor for unauthorized COM objects or changes in existing registrations that could be exploited by attackers.

> **HKEY\_CURRENT\_USER**

HKCU is the abbreviation for this Hive and it contains the root of the configuration information for the user who is currently logged on. This Hive also contains the user’s folders, screen colours, and Control Panel settings are stored here.

***Notable subkeys:***

- **Software**: Contains user-specific software settings and configurations.
- **Control Panel**: Contains settings related to the Control Panel and applets.
- **Environment**: Stores user-specific environment variables.
- **Software\\Microsoft\\Windows\\CurrentVersion**: Contains various settings related to the user’s Windows environment.

***Prime targets:***

1. **Software\\Microsoft\\Windows\\CurrentVersion\\Run:** This subkey is for per-user start-up applications. Be cautious of unexpected entries in this subkey.
2. **Profile Changes:** Look for changes in user profiles, such as desktop settings or preferences, which might indicate tampering.

> **HKEY\_LOCAL\_MACHINE**

HKLM is the abbreviation for this Hive and it contains configuration information and settings that apply to the local computer. SAM and SYSTEM subkeys reside in this Hive and are often prime target for attackers.

***Notable subkeys:***

- **Software**: Contains system-wide software settings and configurations.
- **SYSTEM\\CurrentControlSet\\Services**: Stores information about system services and device drivers.
- **HARDWARE\\Description\\System**: Contains hardware-related information.
- **SOFTWARE\\Microsoft\\Windows\\CurrentVersion**: Contains various system-wide settings for Windows.

***Prime targets:***

1. **SAM\\Domains\\Account\\Users**: This subkey contains user account information for the local machine, including hashed passwords.
2. **System\\CurrentControlSet\\Services:** Attackers may add or modify entries in this subkey to enable malicious services or drivers. Look for services with unfamiliar or suspicious names.
3. **Software\\Microsoft\\Windows\\CurrentVersion\\Run:** Malware often adds entries here to launch itself at system start-up. Check for unusual or unauthorized entries.
4. **Software\\Microsoft\\Windows\\CurrentVersion\\Policies:** Modifications in this subkey may affect system policies. Unauthorized changes might disable security features or impose unwanted restrictions.
5. **Software\\Microsoft\\Windows NT\\CurrentVersion\\Winlogon:** Attackers may modify this subkey to control the login process. Watch for unusual entries, especially those pointing to suspicious files.
6. **SYSTEM\\CurrentControlSet\\Services\\Tcpip\\Parameters:** Modifying network-related keys can enable attackers to control network traffic. Look for unexpected changes in this subkey.

> **HKEY\_USERS**

HKU is the abbreviation for this Hive and it contains all the actively loaded user profiles on the computer. Each user’s SID (Security Identifier) is a subkey that contains user-specific configuration settings.

***Prime targets:***

1. **User Profiles:** Monitor changes to user profiles, especially if you’re seeing additional user profiles that weren’t created by authorized users.
2. **Environment Variables:** Watch for unauthorized modifications to environment variables, which can affect user-specific settings.

> **HKEY\_CURRENT\_CONFIG**

HKCC is the abbreviation for this Hive and it contains information about the hardware profile that is used by the local computer at system start-up.

***Notable subkeys:***

- **Software\\Fonts**: Contains information about system fonts.
- **System\\CurrentControlSet\\Control\\Print\\Environments\\Windows NT x86\\Drivers**: Stores printer driver information.
- **System\\CurrentControlSet\\Services\\Tcpip\\Parameters**: Contains TCP/IP network settings.

***Prime targets:***

1. **System\\CurrentControlSet\\Control\\SystemInformation:** Unauthorized changes in hardware settings could be a sign of tampering.
2. **System\\CurrentControlSet\\Services\\Tcpip\\Parameters:** Keep an eye on the network settings for unusual alterations that could impact network security.
